## 📋 خطة النشر المقترحة

### ① قبل أي حاجة (5 دقايق)

**اعمل نسخة من بياناتك الحالية:**
```bash
cd ~/orange-home-visit
git pull
cp Visits.json Visits.json.bak
cp -r visits visits.bak
```
ودي احتياط مستقل عن أي حاجة تانية.

### ② ظبّط الأسرار — **قبل الرفع**

Streamlit Cloud → Settings → Secrets:
```toml
admin_password  = "الباسورد الحالي بتاعك"
branch_password = "1234567"
device_secret   = "أي سلسلة عشوائية طويلة"
```

⚠️ **لو `admin_password` مش موجود عندك دلوقتي** (يعني كنت داخل بـ`123456`) — لازم تضيفه، غير كده الأدمن هيتقفل.

### ③ افحص قبل الرفع
```bash
python3 preflight.py
```
لازم يقول `✅ جاهز للرفع`. لو قال `⛔ متعملش push` — اتصلّح الأول.

### ④ ارفع
```bash
git add -A
git commit -m "v13: hardening + auth + sync guards"
git push
```

### ⑤ اتأكد بعد إعادة التشغيل — بالترتيب ده

## 💬 خلاصة أمينة

**لو سألتني «هل هتشتغل من أول مرة؟»** — احتمال كبير أيوة، بس مش مضمون. الجزء اللي مقدرتش أختبره حقيقي (Streamlit + GitHub) هو بالظبط الجزء اللي بيتصرّف غير المتوقع.
