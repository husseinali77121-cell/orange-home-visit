# 🟠 Orange Lab — Home Visit Management System (HVMS)

نظام إدارة الزيارات المنزلية لمعمل أورانج لاب — Python + Streamlit.
معمل واحد بفرعين (**La Cite** و **Diamond**): كل فرع له حسابه وقائمة زياراته،
وإدارة الزيارات موحّدة تحت حساب الأدمن.

## المميزات

**الزيارة**
- تسجيل زيارة: الاسم، السن (سنة/شهر)، التليفون (مع مفتاح الدولة)، المدينة/الحي، العنوان، لينك الموقع، الدكتور، الفرع، الميعاد.
- الفرع والدكتور الافتراضيين حسب الحساب: La Cite ← حسين علي · Diamond ← محمد شفيق (يتغيّروا من القائمة عادي؛ القيم في `NEW_VISIT_DEFAULTS` في `app.py`).
- التعرّف على العميل برقم التليفون (حتى لو زياراته السابقة في الفرع الآخر أو في الأرشيف) واستخدام بياناته السابقة بضغطة.
- حالات إضافية في نفس الزيارة (حتى 6)، كل حالة باسمها وتحاليلها.
- اختيار التحاليل بالبحث الذكي من قائمة الأسعار، ⚡ Quick Panels، وخانة لصق رسالة أسعار.
- مانع تكرار: نفس التليفون في نفس اليوم بيوقف الحفظ لحد ما تأكّد إنها زيارة تانية فعلًا.
- حساب آلي: قبل الخصم / بعد الخصم / بدل الانتقال / الإجمالي.
- حالة الزيارة (مجدولة · في الطريق · تمت · ملغية). الزيارة اللي عدّى ميعادها بتظهر في قائمة «حصل إيه؟» في الرئيسية وزيارات اليوم: ✅ تمت · ⏰ تأجيل · ❌ ملغية.
- الدفع: الحالة، الطريقة، المبلغ، التاريخ — مع منع التناقضات.

**الرسائل**
- واتساب للعميل (تأكيد الحجز)، رسالة داخلية للدكتور، ورسالة مختصرة للجروب — أسماء التحاليل فقط مع الإجماليات.
- إرسال الملخص لرقم الدكتور المسجّل، وطلب تقييم بعد الزيارة.
- نسخة للطباعة.

**الإدارة**
- الصفحة الرئيسية بمؤشرات اليوم، زيارات اليوم، بحث وفلاتر، ملف العميل وتصنيفه.
- المتابعات، التقارير، وDashboard للأدمن.
- إدارة الأطباء (إضافة/تعديل/إيقاف + أرقام التليفونات) مع حفظ دائم.
- تصدير **PDF** من الرئيسية والتقارير: A4 بالعرض، ملء كامل للصفحة من غير حواف، ونفس أرقام ملف Excel. مربعات التحاليل والحالات الإضافية فيها أسماء التحاليل بس (الأسعار في أعمدة الحسابات — `SHOW_ITEM_PRICES` في `pdf_export.py` يرجّعها)، وعرض الأعمدة والخط بيتظبطوا لوحدهم عشان الفترة تدخل في أقل عدد صفحات. ملخص الأطباء مابيتمطّش.
- استيراد/تصدير Excel، نسخ احتياطي واسترجاع JSON، إرسال نسخة قاعدة البيانات بالإيميل (أدمن).
- أرشفة الزيارات القديمة، سجل تدقيق وسجل أخطاء.
- 🧹 تنظيف البيانات القديمة (أدمن، من الـ Dashboard): توحيد إملاء المناطق وأسماء الأطباء ومبالغ الدفع، بمعاينة قبل التطبيق.

## الحسابات والصلاحيات

| الحساب | يشوف | الباسورد |
|---|---|---|
| الأدمن | كل الفروع + Dashboard + إدارة النظام | `admin_password` |
| La Cite | زيارات La Cite | `branch_password` |
| Diamond | زيارات Diamond | `branch_password` |

الدخول بالإيميل (لازم يكون في `allowed_emails`) ثم الباسورد، مع خيار «خليك فاكر الجهاز» (توكن موقّع ٩٠ يوم، ٣٠ للأدمن).

## التخزين والمزامنة

- التشغيل على SQLite محلي (`visits.db`) — بيتبني من GitHub عند كل إقلاع.
- **الحفظ الدائم على GitHub** بعد كل إدخال/تعديل:
  - `visits/YYYY-MM.json` — ملف لكل شهر
  - `Visits.json` — مرآة كاملة
  - `doctors.json` — الأطباء
  - `archive/` — الزيارات المؤرشفة
- حُرّاس الحفظ بيمنعوا رفع قاعدة فاضية أو أصغر من الموجود على GitHub.
- قراءة حالة GitHub بتحصل وقت الإقلاع، وقبل كل حفظ، وكل 10 دقايق للتأكد من الاتصال — مش مع كل ضغطة.
- لو الرفع فشل، بانر أحمر بيفضل ظاهر لكل المستخدمين بزر «حاول الرفع» لحد ما حفظ ينجح.

> ⚠️ الريبو فيه بيانات مرضى — لازم يفضل **Private**.

## الإعدادات (Secrets)

`.streamlit/secrets.toml` محليًا، أو Settings → Secrets على Streamlit Cloud:

```toml
# إجباري
allowed_emails  = ["admin@...", "branch1@...", "branch2@..."]
admin_password  = "..."
branch_password = "..."
device_secret   = "سلسلة عشوائية طويلة"
github_token    = "..."            # صلاحية Contents: Read & Write
github_repo     = "owner/repo"

# اختياري
github_branch   = "main"
smtp_user       = "..."            # لإرسال النسخة بالإيميل
smtp_password   = "..."            # App Password من نفس حساب smtp_user
token_version   = 1                # زوّده لإلغاء كل الأجهزة الموثوقة
auto_done_grace_min = 120          # المهلة بعد الميعاد قبل ما الزيارة تتحسب «عدّى ميعادها»
overdue_mode    = "ask"            # "auto" يرجّع التحويل الآلي لـ «تمت»
gh_recheck_min  = 10               # كل كام دقيقة يتأكد من اتصال GitHub
ui_sidebar      = "1"              # "0" يرجّع الشريط العلوي فقط
```

ملف الأسرار ممنوع يدخل الريبو (موجود في `.gitignore`).

## التشغيل

```bash
pip install -r requirements.txt      # streamlit>=1.45 إجباري
streamlit run app.py
```

النشر على Streamlit Cloud: New app → اختر الريبو و`app.py` → ضيف الـ Secrets → Deploy.
التفاصيل في `DEPLOY.md`.
